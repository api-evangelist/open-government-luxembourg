This dataset complies with pan-European standards which are part of the INSPIRE theme ‘Geographic Grid System’ and conforms to the data specifications defined for that theme. According to the INSPIRE data specification for the theme Geographical Grid Systems, a geographical grid system is defined as following : "Harmonised multi-resolution grid with a common point of origin and standardised location and size of grid cells".
